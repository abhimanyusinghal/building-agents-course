# INC-2214 — Password reset says "account not found" for valid accounts

## What happened
Reset lookups were case-sensitive while addresses are stored lowercase. Every
user who typed an Uppercase e-mail was told the account did not exist. 41
support tickets in two days.

## Resolution and regression risk
Lookups normalised to lowercase. Any new code path that touches e-mail must be
case-insensitive; a regression here is invisible to happy-path tests because
test fixtures habitually use lowercase addresses.
